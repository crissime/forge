# Contexte Forge Master

Ce dossier sert de memoire projet pour le simulateur Forge Master.

## Fichiers

- [game-overview.md](./game-overview.md): resume du jeu, des boucles principales et des systemes importants.
- [stats-and-builds.md](./stats-and-builds.md): notes sur les stats, les objets, pets, monture, sorts et talents.
- [simulator-context.md](./simulator-context.md): decisions prises pour notre simulateur, limites connues et points a verifier.
- [sources.md](./sources.md): liens utiles, sources communautaires, outils existants et notes d'utilisation.

## Intention du projet

Le simulateur local ne cherche pas a remplacer ForgeMaster Helper de 1vcian. L'objectif est de completer cet outil avec:

- une lecture orientee PvP;
- une comparaison rapide de drops;
- des recommandations simples d'amelioration;
- une structure compatible avec l'import JSON de `1vcian/fm`;
- une app deployable en front expose publiquement, API interne et Postgres.

## Date de contexte

Notes creees le 16 juin 2026. Forge Master est un jeu vivant: les valeurs exactes, caps, sorts, talents et formats JSON peuvent changer apres une mise a jour du jeu ou du projet communautaire.
